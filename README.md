# めっちゃGPT

自分のOpenAI APIキーとDiscord BOTトークンで動かす、Windows x64向けDiscordサポートBOTです。開発ソースは非公開です。

## ダウンロード

[正式配布ファイルはこちら](https://github.com/kairi-2525/meccha-gpt-releases/releases)。インストーラー名は MecchaGPT-Setup-VERSION-x64.exe です。GitHubが表示する Source code ZIP はアプリ本体ではありません。

Windowsの発行元を認証するAuthenticode署名は付いていません。SmartScreenの警告や、管理端末・Smart App Controlの実行ブロックが発生する場合があります。セキュリティ機能を無効化して使うことは推奨しません。

## 署名を確認する

インストーラーと同名の .minisig を取得し、[Minisign](https://jedisct1.github.io/minisign/)で検証します。公開鍵は同リポジトリの release-public-key.txt に掲載します。一度確認した公開鍵は手元に控え、更新時に配布ファイルと一緒に差し替えないでください。

```powershell
minisign -Vm .\MecchaGPT-Setup-VERSION-x64.exe -P "控えておいた公開鍵"
```

Minisignはファイル改ざんを検出するための独自鍵による署名です。Windowsの発行元表示や警告は変更しません。SHA256SUMSの一致だけでは発行元を認証できません。

## 初期設定

1. Discord Developer Portalで自分のBOTを作り、Message Content IntentとServer Members Intentを有効にします。
2. BOTをサーバーへ招待します。bot と applications.commands を使い、閲覧・履歴の読み取り・メッセージ送信など必要な権限を付けます。Administrator権限は一律に与えないでください。
3. インストーラーを実行し、めっちゃGPTを起動します。Node.jsの別途導入は不要です。
4. 「設定」で自分のOpenAI APIキー、Discord BOTトークン、利用可能なモデル名を入力します。APIの課金設定とモデル利用権限は利用者側で用意します。
5. キャラ名、一人称、口癖、口調などを必要に応じて変更し、「保存する」を押します。
6. 「BOTを起動」を押します。Discord側の管理者専用 /bot-settings コマンドで自動応答チャンネル等を設定します。

DMには応答しません。自動応答外でのメンション応答は初期状態ではOFFです。キャラ設定で閲覧・送信権限や安全ルールは変更できません。同じBOTトークンを他のPC・開発版と同時起動しないでください。

ソフトの利用は無料ですが、OpenAI APIの料金はキー所有者に発生します。

## 更新・停止・保存データ

- 起動時にGitHubの更新情報を確認します。署名が確認できた新しい版だけ案内します。確認先に接続できなくても現在の版を起動できます。
- v0.2.3以降は、アプリの「更新する」からダウンロード・署名確認・BOTの安全停止・インストールまで進められます。自動では実行せず、利用者がボタンを押した場合だけ更新します。更新後は設定画面が開き、BOTは停止した状態です。
- ダウンロード・署名確認が完了するまではBOTを止めません。停止を確認できない場合や署名が一致しない場合は、強制終了や未検証ファイルの実行をせず中断します。
- v0.2.2以前からv0.2.3への初回更新、またはアプリ内更新を使えない場合は、BOTを停止して画面を閉じ、新しいインストーラーを手動で実行してください。
- v0.2.2以降は、設定画面を閉じてもBOTが独立して動き続けます。停止するときはアプリを開き直して「BOTを停止」を押し、停止完了を待ちます。
- 「設定」の「Windowsログイン時の起動」で、自動起動のON／OFFと「ウィンドウあり／なし」を選べます。初期状態はOFFです。ウィンドウなしでは起動用アプリも終了し、BOTの実行プロセスだけが残ります。
- ウィンドウありでは起動・停止・ログ画面を表示します。画面を閉じてもBOTは停止しません。画面なしでもログは保存され、アプリを開き直して確認できます。
- 更新・アンインストール前にはBOTを停止し、設定画面を閉じてください。BOTが稼働中、または状態を確認できない場合は強制終了せず中断します。
- 保存先は原則 %LOCALAPPDATA%\MecchaGPT です。APIキーとBOTトークンはWindows DPAPIで暗号化して保存します。
- アンインストールしても利用者データは残します。完全削除は停止後に保存先を自分で削除してください。
- キーやBOTトークンを変更すると別プロファイルになります。旧履歴は削除しませんが、新しいプロファイルで応答先等の再設定が必要です。

## プライバシーと問い合わせ

[プライバシーについて](PRIVACY.md)を確認してください。APIキー、BOTトークン、非公開会話、個人情報をIssuesや添付ファイルへ投稿しないでください。問い合わせはこのリポジトリのIssuesを使用してください。

## モデル・速度の設定

配布版の新規利用時の推奨値は `gpt-6-luna` / `medium` / Fast です。BOTを停止して「設定」画面からモデル名、推論エフォート、Fast／標準を変更できます。メインと調査担当に同じ設定を適用し、次回起動から反映します。以前の保存設定に速度の指定がない場合は、追加料金を勝手に発生させないため標準を維持します。

Fastには追加料金がかかり、利用可能なモデル・エフォート・速度はAPIアカウントによります。利用不可時に別モデルや別の課金方式へ自動で切り替えません。詳細は[OpenAIのFast mode](https://developers.openai.com/api/docs/guides/fast-mode)と[モデル情報](https://developers.openai.com/api/docs/models/gpt-6-luna)をご確認ください。CLI版やホスト側の既存API設定は変更しません。
