# めっちゃGPT

Windows 向け Discord サポート BOT の公式配布ページです。

**現在、初回配布の準備中です。まだインストーラーは公開していません。**

## 配布予定の形

- 各利用者が自分の OpenAI API キーと Discord BOT トークンを設定して利用します。
- 利用者の PC で動作し、OpenAI API の利用料金はそのキーの所有者に発生します。
- キャラクターの名前・一人称・口癖・口調などを設定できる形を予定しています。
- 起動時に更新を確認します。更新情報を取得できなくても、インストール済みの版の起動は止めません。
- BOT 自体の利用には Discord と OpenAI API への接続が必要です。

## このリポジトリについて

このリポジトリには利用者向けの案内、変更履歴、完成した配布ファイルだけを置きます。開発ソースコードは公開しません。

公開後のインストーラーは [Releases](https://github.com/kairi-2525/meccha-gpt-releases/releases) から案内します。API キーや BOT トークンを Issues、コメント、添付ファイルに書かないでください。

配布条件・対応環境・署名の確認方法は、初回リリース時に案内します。
